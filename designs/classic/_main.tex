% envelopes). scrlttr2 builds it from fromname+fromaddress by default, which
% overran its fixed-width zone and collided with the firsthead for long legal
% names. This line is postal convenience, not a §14 UStG field, so the short

% Rechnungsnummer is placed inside firsthead to avoid the overlap bug

% the table and the location sidebar content overlapped visually).
% Moving Rechnungsnummer into the table and removing the [t][\headheight]
% height constraint lets the parbox grow to fit all rows cleanly.
\setkomavar{location}{}
